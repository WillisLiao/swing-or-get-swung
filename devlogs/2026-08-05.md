# 2026-08-05

## Mode swap landed; movement regression fixed

The seed/linebreak objective and its tactics/relay files were removed; the live game now runs on `RiftlineMatch` with Deathmatch and Bomb modes selectable from the practice screen or `--mode=`.
A post-handoff regression left offline and host duelists unable to move: `RiftlineMatch` never armed `match_active` when the phase went LIVE, so `Duelist.drive()` no-opped.
`RiftlineMatch._set_phase` now calls `_set_duelists_active(phase == LIVE)` so entering LIVE arms every registered duelist; `riftline_modes_exercise.gd` asserts `match_active` after going live.
Redeployed to iPhone and iPad; movement restored.
