# 2026-08-06

## Circular Nuke Rush arena

- Rebuilt Concourse as a symmetric circular 5v5 arena with opposing SUN and
  VOID bases, five spawn positions per side, circular flank routes, and a
  central procedural nuke pickup room.
- Added Nuke Rush as a complete match mode: neutral center pickup, carried and
  dropped states, steals by either team, immediate victory at the enemy base,
  and timeout victory based on each team's furthest push. Exact ties receive a
  30-second overtime.
- Added replicated objective state, protocol version 10 support, HUD timer and
  progress indicators, objective callouts, practice-mode selection, and a
  procedural `pulp_lit` nuke model. No imported art or textures were added.
- Extended the map and mode exercise coverage for layout, landmark, pickup,
  drop, steal, delivery, timeout, and network descriptor behavior.
- Verified with the serial headless import and every `tools/*_exercise.gd`
  runner; all passed. Also visually checked overview, pickup-room, and live 5v5
  captures, then ran a concurrent LAN host/join smoke test. The only network
  diagnostic was the already documented ENet MTU warning.
- Device deployment and touch playtesting were not performed in this session.

## Nuke Rush 4v4 follow-up

- Revised the mode from five to four players per team. Concourse now exposes
  four symmetric spawn slots at each base, and Full Line offline practice
  launches four teammates per side.
- Nuke Rush LAN configuration and received session descriptors are normalized
  to 4v4, while other modes retain their existing supported team sizes.
- Updated the practice-mode copy, formation diagram, exercise expectations,
  handoff, and pull-request description to match the new player count.
- Added `nuke_rush_arena.tscn` as the canonical Concourse scene used by the
  game. Its `RiftlineMap` child builds the same procedural geometry in the
  Godot editor, so the full circular map is visible when the scene is opened.
